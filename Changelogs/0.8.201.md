# 0.8.201

## What's new

- `ObjCInterfaceIndexer` takes `suppliedClasses`, Swift classes without a class object such as generic ones, and indexes, renders and snapshots them.

## Fixes

- `diff` now reports a protocol that newly adopts a protocol with required members as breaking.
- Methods with unlabeled arguments, such as `add::`, now render every argument.
- Array fields of structs and arrays of arrays now render all their dimensions.
- `stripSynthesizedMethods` no longer removes a `set…:` method declared beside a read-only property.
- Fixed empty method names in arm64_32 (watchOS) files.
- Fixed a crash when resolving IMP addresses of arm64e methods in loaded images.
- Classes and categories that implement `+load` are no longer indexed twice.
- `objc.methods` now reads every method list in `__objc_methlist`.
- `ivarLayout(in:)` now keeps bytes of 0x80 and above.
- `Transformer.CType` no longer rewrites part of a longer type, such as `unsigned long`.

## Compatibility

- Requires MachOKit 0.55.100 and swift-objc-dump 0.8.102 or later.
- Removed `ObjCRenderingContext.currentArray` and its `init` parameter; drop any use of them.
